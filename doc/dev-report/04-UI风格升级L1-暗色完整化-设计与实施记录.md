## 一、背景与目标

L0 把圆角、阴影、动效时长、z-index 收敛成了令牌，但**颜色**只收敛了"遮罩/阴影色"一类，遗留三类问题：

1. **浅色泄漏**：组件里大量使用 `--vp-c-danger*` / `--bg-color` 这类**在本站根本不存在的变量名**，`var()` 的 fallback（浅色字面量）实际成了唯一取值，暗色下渲染出发光的浅色块。
2. **语义色缺位**：成功/警告/危险/信息四类语义色没有统一来源，各组件各写各的 hex。
3. **刻度外零散值**：L0 白名单里剩下的品牌绿一族、灯箱 hover 加亮、`transition: all 0.35s` 未纳入令牌。

**目标**：把上述三类收敛掉，且**以"接通主题已有色板"为主**，而不是自造一套语义令牌。本期**不做**布局重构、不做配色改版。

## 二、实测发现（本期方案的依据）

### 发现 A：`--vp-c-danger*` / `--vp-c-warning*` / `--vp-c-info*` 在本站不存在

这些是 **VuePress 默认主题**的命名，本站用的是 hope。逐处核对：

- hope 的 `templates/palette/{color,font,layout,transition,generator}.scss` 只有 `accent / bg / text / border / divider / shadow / control` 一族，**没有 danger / warning / info / success**；
- 全量 `node_modules/.pnpm` 下的 `*.scss` / `*.css` / `*.js` 搜 `--vp-c-danger:` / `--vp-c-warning:` / `--vp-c-info:` **零命中**；
- 浏览器实测 `getComputedStyle(document.documentElement).getPropertyValue('--vp-c-danger-content')` 返回**空串**。

→ 组件里的 fallback（`#fdecec` / `#eaf3ff` / `#fff7e6` / `#a33`）是唯一取值，暗色下就是浅色块。

### 发现 B：`--bg-color` / `--border-color` 全站无定义

`unlock/*` 里反复出现 `var(--bg-color, #fff)`、`var(--border-color, #e5e7eb)`。同样全量搜过：**这两个变量在主题与所有依赖里都没有定义**，于是也一直是字面量。

后果最刺眼的一处：`.unlock-modal` 背景是 `var(--bg-color, #fff)` → **暗色模式下弹窗是一整块纯白**。

### 发现 C：主题其实早就给了一整套明暗双套语义色板

`@vuepress/helper/dist/client/styles/colors.css` 提供：

- `--vp-c-{red,yellow,blue,green,grey,purple,indigo}-{text,hover,bg,soft}`，**明暗双套**；
- `--vp-c-white` / `--vp-c-black`（暗色下反转）。

`@vuepress/plugin-markdown-hint` 的提示容器正是消费这套色板（`--vp-c-blue/yellow/green/red/grey/purple-*`）。

→ **不需要自造语义令牌**，把组件接到这套色板上即可。

### 额外发现（计划外、同类根因）：`--vp-c-text-1/2/3` 与 `--vp-c-brand` 也不存在

`DocEditor` 家族用了默认主题的 `--vp-c-text-1/2/3` 表示三级文字层级，hope 下无定义 → 三级层级全部塌陷为继承色。`var(--vp-c-accent, var(--vp-c-brand))` 里的 `--vp-c-brand` 同理是死 fallback。一并修正为 `--vp-c-text` / `--vp-c-text-mute` / `--vp-c-text-subtle` / `--vp-c-accent`。

### 死代码发现

- `GlobalUnlock.vue` **从未被 `client.ts` import**；
- `UnlockContent.vue` 虽注册为组件，但全库 markdown 中**零处使用**（无 `<UnlockContent` / `<GlobalUnlock` 命中）。

→ 两组件无法在真实页面渲染验证，故验收改用"强制 Vite 编译并检查注入 CSS"的路线（见第五节）。

## 三、实施方案

### 3.1 新增令牌（6 项，`docs/.vuepress/styles/palette.scss`）

| 令牌                          | 取值                                                            | 用途                                                |
| ----------------------------- | --------------------------------------------------------------- | --------------------------------------------------- |

| `--jg-c-brand-border`         | `(light: rgb(62 175 124 / 45%), dark: rgb(74 185 138 / 50%))`   | "阅读全文"按钮描边                                  |
| `--jg-c-brand-glow`           | `(light: rgb(62 175 124 / 16%), dark: rgb(74 185 138 / 22%))`   | 品牌绿光晕阴影的**颜色令牌**（结构字面量引用它）    |

| `--jg-shadow-brand-hover`     | `"0 10px 24px var(--jg-c-brand-glow)"`                          | 阅读全文按钮 hover                                  |

## 六、暗色对比度抽查

工具：浏览器计算样式 → alpha 合成到实际背景 → WCAG 相对亮度公式。

| 元素         | 前景                     | 有效背景        | 对比度 | 判定（AA 正文 4.5:1） |
| ------------ | ------------------------ | --------------- | ------ | --------------------- |
| 正文 `p`     | `rgba(235,235,245,.604)` | `rgb(27,27,31)` | 6.04   | 通过                  |
| 正文 `li`    | `rgba(235,235,245,.86)`  | `rgb(27,27,31)` | 10.97  | 通过                  |
| 标题 `h2`    | `rgba(235,235,245,.86)`  | `rgb(27,27,31)` | 10.97  | 通过（大字号 AAA）    |
| 表格 `th`    | `rgba(235,235,245,.86)`  | `rgb(27,27,31)` | 10.97  | 通过                  |
| 表格 `td`    | `rgba(235,235,245,.86)`  | `rgb(22,22,24)` | 11.46  | 通过                  |
| 行内 `code`  | `rgba(235,235,245,.604)` | `rgb(39,41,47)` | 5.46   | 通过                  |
| 引用         | `rgba(235,235,245,.604)` | `rgb(27,27,31)` | 6.04   | 通过                  |

**结论**：抽查项全部通过，无需处置。

## 七、遗留与说明

- 站点实际**未使用** `unlock/*` 两个组件（无页面引用），本期对它们的改动属"消除潜在暗色缺陷 + 保持代码一致"，**不影响当前线上观感**。若后续启用，需真机复测一次。
- 明色下 `Toggle` / 组件内 `#64748b` 一类灰阶被替换为主题中性色，属**近似**而非等值；方向是与全站中性色统一，判定为可接受。
- 未纳入本期的 `transition: all`（`GlobalUnlock.vue` / `LayoutToggle.vue`）已使用令牌时长，仅**属性集合**仍为 `all`；属性能微优化，非暗色问题，留待后续动效专项。

> **L2 更新（2026-10-02）**：上条遗留已由 L2 清偿 —— 两处 `transition: all` 均改为显式属性枚举（`GlobalUnlock.vue` 的 `.read-more-btn` 枚举 `transform`/`box-shadow`；`LayoutToggle.vue` 枚举 `color`/`background-color`/`border-color`/`transform`）。详见 `05-UI风格升级L2-动效编排层-设计与实施记录.md`。
